# Glosario (alemán – español)

| Término | Significado |
|---|---|
| **Aufschluss** | Punto de exploración del subsuelo (sondeo, calicata, sondeo de penetración) |
| **Bodengutachten / Baugrundgutachten** | Informe geotécnico |
| **Baugrundmodell** | Modelo del terreno (interpretación 3D de capas y parámetros) |
| **Bohrprofil / Schichtenverzeichnis** | Perfil de sondeo / registro de capas (dibujo DIN 4023 / descripción por capas) |
| **Bohrung (B, BK, KB, RKS)** | Sondeo (Kernbohrung = con extracción de testigo; RKS = Rammkernsondierung) |
| **Bodenart** | Tipo de suelo (Sand, Kies, Schluff, Ton, …) |
| **DIN 4023** | Norma alemana de representación gráfica de sondeos (rev. 2023) |
| **DIN EN ISO 14688-1** | Identificación y clasificación de suelos (descripción) |
| **DPH / DPL / DPM** | Sondeo dinámico (Rammsondierung) pesado / ligero / medio; valor `N10` = golpes por 10 cm |
| **CPT / Drucksondierung** | Sondeo de penetración estática; `q_c` resistencia de punta, `f_s` fricción. En los planos actuales los sondeos `DS` se excluyen (`geo_agent/bohrprofil.py:32`); que `DS` sea Drucksondierung está **[a confirmar]** |
| **GOK (Geländeoberkante)** | Cota del terreno en el punto del sondeo |
| **GWM (Grundwassermessstelle)** | Piezómetro |
| **Grundwasser (GW)** | Agua subterránea; *angetroffen* = encontrada al perforar, *Ruhewasserspiegel* = nivel estabilizado |
| **HGW / MGW / Bemessungswasserstand** | Nivel freático máximo / medio / de diseño |
| **Homogenbereich** | Unidad de terreno con propiedades homogéneas (DIN 18300 y sig.) |
| **Kornbereich, Nebenanteil, Konsistenz, Kalkgehalt** | Rango granulométrico (f/m/g), fracción secundaria (schwach/stark), consistencia (weich…fest), contenido de cal (k+, k++) |
| **Lageplan** | Plano de situación |
| **Längsschnitt** | Perfil longitudinal (aquí: geológico, con el túnel) |
| **Legende / Zeichenerklärung** | Leyenda del plano |
| **NHN / NN** | Normalhöhennull (DHHN92/2016) / Normalnull (DHHN12): referencias de altura |
| **OCG (Optional Content Group)** | Capa de un PDF; conserva las capas del CAD |
| **OK / Achse / Sohle (Tunnel)** | Clave / eje / solera del túnel |
| **Rechtswert / Hochwert** | Coordenada este / norte (Gauß-Krüger; en UTM: Ostwert / Nordwert) |
| **Schraffur / Signatur** | Patrón gráfico de la Bodenart en la columna (puntos, círculos, rayas) |
| **Station / Tunnelmeter (TM)** | Progresiva a lo largo del eje |
| **Überhöhung** | Exageración vertical del dibujo |
| **Sidebar (swissgeol)** | Columna de profundidades; *AAboveB* = valores apilados, *AToB* = intervalos `a–b` |
| **Strip log (swissgeol)** | Columna gráfica del sondeo |
| **Ground truth** | Datos de referencia verificados para medir la extracción |
